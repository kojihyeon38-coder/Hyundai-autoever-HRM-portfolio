# Hyundai AutoEver HRM Portfolio

정적 HTML 기반의 포트폴리오입니다. 별도 서버가 없어 GitHub Pages에서 빠르게 열립니다.

## GitHub Pages 배포
1. GitHub에서 새 Public repository 생성
2. 이 폴더의 `index.html`과 `portfolio.pdf` 업로드
3. Repository의 `Settings` → `Pages`
4. `Build and deployment`에서 `Deploy from a branch` 선택
5. Branch를 `main`, Folder를 `/ (root)`로 선택 후 Save
6. 잠시 뒤 생성되는 `https://사용자명.github.io/저장소명/` 주소를 지원서에 입력

## 권장 저장소 이름
`hyundai-autoever-hrm-portfolio`
